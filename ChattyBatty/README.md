# ChattyBatty

This folder holds the ChattyBatty app. Setup, features, security and
troubleshooting are documented in the [main README](../README.md).

Quick start, from this folder:

```bash
npm install

# Try it locally with stand-in accounts (two terminals):
npm run emulators
npm run dev:emulators

# Or use real Google sign-in with your Firebase project:
npx firebase login
npm run setup
npm run dev
```
